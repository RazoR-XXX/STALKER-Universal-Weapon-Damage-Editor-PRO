# STALKER-Universal-Weapon-Damage-Editor-PRO_2.0
Универсальный редактор урона оружия для всей трилогии S.T.A.L.K.E.R.

🎯 Возможности

    🔄 Универсальность - Работает со всеми частями: ТЧ, ЧН, ЗП

    ⚡ Автоопределение - Сам находит версию игры и архивы

    🔧 Умные исключения - Не ломает баланс гранат, апгрейдов

    🎮 Совместимость - Работает с любыми сборками и модами

    📊 Гибкие настройки - Множители от 1x до 10x и кастомные значения

    🎨 Стильный интерфейс - Оформление в духе STALKER

🚀 Быстрый старт

    Скачайте последнюю версию из Releases

    Запустите STALKER_Weapon_Editor.exe

    Выберите папку с игрой

    Установите множитель урона

    Нажмите "Запустить обработку"

🛠 Технические детали

    Автораспаковка архивов (.db0, .db и т.д.)

    Автоопределение структуры папок (config/configs)

    Рекурсивная обработка всех .ltx файлов

    Безопасное изменение только параметров урона

    Подробное логирование всего процесса

❓ Частые вопросы

Q: Работает ли с модами?
A: Да! Автоопределение работает с большинством сборок.

Q: Безопасно ли это?
A: Да, создаются только конфиги в gamedata, оригинальные файлы не трогаются.

Q: Какие параметры меняются?
A: Только hit_power и silencer_hit_power, всё остальное без изменений.
